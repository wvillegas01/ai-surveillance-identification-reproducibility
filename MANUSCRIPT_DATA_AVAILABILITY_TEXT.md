# Data availability statement for the manuscript

Paste the paragraph below into the manuscript. Both DOIs are final: the concept
DOI resolves to the latest version, and the version DOI identifies v1.0.2, which
produced the results reported in the manuscript.

---

The three sources analysed in this study are public. The AI surveillance index
is deposited in Mendeley Data (dataset gjhf5y4xjp, version 4) under a CC BY 4.0
licence; the Digital Society Project v8 dataset is distributed at
https://digitalsocietyproject.org/data/; and the V-Dem v16 Country-Year
Full+Others dataset is distributed at https://v-dem.net/data/the-v-dem-dataset/.
The reproducibility package is available at
https://github.com/wvillegas01/ai-surveillance-identification-reproducibility
and archived at Zenodo under the concept DOI
https://doi.org/10.5281/zenodo.23346779. The results reported in this version of
the manuscript were produced by package version 1.0.2
(https://doi.org/10.5281/zenodo.23539189). It contains the master country-level table
recording treatment status, cohort assignment, and every exclusion; the
reconstructed treatment dates under the five dating rules; the country-level
evidence table and the operational-status coding of the records that fix each
date; the country-name correspondence table; the log of corrections applied to
the source files; the analysis scripts that reproduce every figure, table, and
numerical result reported here from the raw sources; a verification script that
checks the reported values and compares regenerated tables with the reference
results; and the specification of both software environments (Python 3.12 with
`differences` 0.3.0 and `csdid` 0.4.2; Python 3.8 with `differences` 0.1.2). The
Digital Society Project and V-Dem files are not redistributed; the scripts
verify the downloaded files against their SHA-256 checksums. All resampling
procedures use a fixed seed (20261011).
